# My Portfolio Website

## About the Project

This is my personal portfolio website, developed as part of my JavaScript for Web Development course.

The website presents my background, projects, photography gallery, skills and an interactive feedback form.

The project was developed using HTML5, CSS3 and Vanilla JavaScript, with a focus on accessibility, responsive design and interactive features.

## Features

### Website Pages
- Home page
- About page
- Projects page
- Nature photography gallery
- Feedback form
- Dynamic skills showcase

### Feedback Form
- JavaScript form validation
- Required field validation
- Email and URL validation
- Live character counter
- Error messages
- Success confirmation message

### Skills Showcase
- Data-driven skills using JavaScript objects
- 8 skills across 3 categories
- Dynamic skill card generation
- Category filtering
- Alphabetical sorting (A to Z and Z to A)
- Combined filtering and sorting
- Dynamic skill count

### Accessibility Features
- Small, Medium and Large text options
- Normal and High Contrast modes
- Keyboard-accessible controls
- ARIA attributes for improved screen reader support
- Accessibility preferences saved using localStorage
- Preferences maintained after refreshing the page

## How to Use the Features

### Feedback Form

1. Open the Feedback page.
2. Enter your name and email address.
3. Select a topic of interest.
4. Write comments and check the live character counter.
5. Submit the form to see validation messages or a success confirmation.

### Skills Showcase

1. Open the Skills page.
2. Select a category from the filter.
3. Choose the sorting order.
4. Combine category filtering and sorting.
5. Check the dynamically updated skill count.

### Accessibility Settings

1. Open the Accessibility Settings panel.
2. Select Small, Medium or Large text.
3. Switch between Normal and High Contrast.
4. Use keyboard navigation to operate the controls.
5. Refresh the page to verify that preferences are saved.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Navigate through the website using the navigation menu.

## Feedback Form Notice

The feedback form validates user input and displays a confirmation message in the browser.

It does not send or store feedback on a server because this project does not use a backend.
