
# My Portfolio Website

## About the Project

This is my personal portfolio website. It presents my background, projects, gallery, skills and feedback form.

The website was developed using HTML, CSS and Vanilla JavaScript.

## Features

- Home page
- About page
- Projects page
- Gallery page
- Feedback form with JavaScript validation
- Live character counter for comments
- Success and error messages
- Skills showcase with category filtering
- Skills sorting (A to Z and Z to A)
- Accessibility settings
- Small, Medium and Large text options
- High Contrast mode
- Accessibility preferences saved using localStorage

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
- Git and GitHub

## Project Structure

- index.html – Home page
- about.html – About page
- projects.html – Projects page
- gallery.html – Gallery page
- feedback.html – Feedback form
- skills.html – Skills showcase
- style.css – Main stylesheet
- feedback.css – Feedback form styles
- skills.css – Skills page styles
- js/ – JavaScript files
- images/ – Website images
- screenshots/ – Screenshots showing project features and testing
- TESTING.md – Project testing checklist and results

## Testing

Project testing details and verification results are documented in [TESTING.md](TESTING.md).

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in a web browser.
4. Navigate through the website using the navigation menu.

## Feedback Form Notice

The feedback form validates user input and displays a confirmation message in the browser. It does not send or store feedback on a server.
