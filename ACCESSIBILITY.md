
# Accessibility Features

## 1. Overview

The portfolio website includes an accessibility panel that allows users to customize the appearance of the website.

## 2. Text Size Options

Users can choose between three text size options:

- Small
- Medium
- Large

These options help users adjust the text size according to their reading preferences.

## 3. Contrast Options

The accessibility panel provides two contrast modes:

- Normal Contrast
- High Contrast

High Contrast improves the visual distinction between text and background.

## 4. Saving User Preferences

The website uses JavaScript localStorage to save accessibility preferences.

This allows the selected text size and contrast settings to remain active after the browser page is refreshed.

## 5. Keyboard Accessibility

Users can navigate the accessibility controls using the keyboard.

- Tab key: Move between controls.
- Enter key: Activate the selected control.

The accessibility panel provides users with options to customize text size and contrast. User preferences are saved using localStorage so that the selected settings remain available after refreshing the page.
