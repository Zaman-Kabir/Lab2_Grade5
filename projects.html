Project 1

Personal Portfolio Website

This project is a personal portfolio website that I am building while learning the fundamentals of HTML and CSS.

Challenge

Building a personal portfolio website was a completely new experience for me because I had very little previous knowledge of web development. As a beginner, I found many parts of the process challenging, especially understanding the code and knowing which code should be used and where it should be placed.

Even small steps sometimes felt difficult because I was still learning how HTML and CSS work together. I approached the project gradually, working through each step and trying to understand the purpose of the code as I progressed.

Solution

To manage these challenges, I tried to work on the project step by step instead of attempting everything at once. I used course materials and other learning resources to understand the concepts and find guidance when I was unsure about something.

I first focused on creating the basic HTML structure and then gradually worked on the CSS styling and other features. Breaking the project into smaller tasks made the process easier to follow and helped me understand how the different parts of the website work together.

What I Learned

As a beginner, I understand that it is not possible to learn everything about web development in a short period of time. However, working on this project has given me a basic understanding of how a website is created and how HTML and CSS work together.

I have started to understand how HTML provides the structure of a webpage and how CSS can be used to change its appearance and layout. Most importantly, this project has shown me that learning web development is a gradual process, and I need to continue practising to improve my skills.

Project 2

Beginner Python Exercises

As part of my introduction to programming, I have been working on small beginner-level Python exercises. These exercises are part of my early learning process and have helped me become more familiar with programming and the basic idea of writing and running code.

Challenge

Since programming is new to me, understanding the logic behind the code has been one of the main challenges. At the beginning, even simple exercises could be difficult because I needed to understand what each part of the code was doing and how the different parts worked together.

Solution

I approached the exercises gradually and tried to work through them step by step. When I found something difficult, I reviewed the learning materials and practised similar examples to understand the concept better. Repeating basic exercises has helped me become more familiar with Python.

What I Learned

These exercises have given me an introduction to programming with Python. I am still at the beginner stage, but I have started to understand how programming requires both logical thinking and practice. I have also learned that making mistakes and correcting them is a normal part of learning to code.
