# Project Structure Documentation

## 1. Project Overview

The portfolio website is organized into separate HTML, CSS, JavaScript, resource, and documentation files.

This structure makes the project easier to understand, maintain, and update.

## 2. HTML Files

The HTML files define the structure and content of each website page.

- `index.html` – Main home page.
- `about.html` – Personal background and information.
- `projects.html` – Portfolio projects.
- `gallery.html` – Image gallery.
- `feedback.html` – Feedback form.
- `skills.html` – Dynamic skills showcase.

## 3. CSS Files

The CSS files control the website's layout, appearance, and styling.

- `style.css` – Main website styling.
- `feedback.css` – Feedback form styling.
- `skills.css` – Skills showcase styling.
- `js/a11y.css` – Accessibility panel styling.

## 4. JavaScript Files

The JavaScript files provide interactive functionality.

- `js/feedback.js` – Form validation, character counter, and success message.
- `js/skills.js` – Skills data, dynamic rendering, filtering, and sorting.
- `js/a11y.js` – Accessibility settings and preference persistence.

## 5. Resource Folders

- `images/` – Website images and visual resources.
- `screenshots/` – Screenshots of project features and testing.

## 6. Documentation Files

- `README.md` – Project introduction and setup instructions.
- `TESTING.md` – Project testing checklist and results.
- `ACCESSIBILITY.md` – Accessibility feature documentation.
- `FEEDBACK.md` – Feedback form documentation.
- `SKILLS.md` – Skills showcase documentation.
- `PROJECT_STRUCTURE.md` – Project structure documentation.
- `.gitignore` – Specifies files excluded from Git tracking.

## 7. Technologies

The project uses:

- HTML5
- CSS3
- Vanilla JavaScript
- Git
- GitHub

## 8. Conclusion

The project follows a simple file organization structure. HTML manages page content, CSS controls presentation, and JavaScript provides interactive functionality.

Separating these responsibilities makes the project easier to maintain and develop.
